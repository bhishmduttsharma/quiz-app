# Feature Summary

## Student Features

- Secure registration and login
- Technology-wise quiz selection
- Difficulty levels: Basic, Intermediate, Advanced
- Timed quiz sessions with progress tracking
- Auto-submit when time expires
- Instant answer feedback
- Bookmark questions for later review
- Review mode after submission
- Result history and performance badges
- Downloadable PDF certificates
- Personal profile with avatar, college, and bio

## Admin Features

- Protected admin dashboard
- Admin account creation through a private invitation code
- Create, edit, delete, and hide questions
- Manage technologies and difficulty levels
- Generate secure student practice links for selected technology and level
- View students and platform attempts
- Monitor top performers and subject analytics
- Track platform-wide average score and activity

## Secure Shared Practice Links

Admins can generate a student link for a selected technology and difficulty level. The shared link:

- uses up to 30 questions
- gives each logged-in student a different deterministic shuffle
- shuffles answer options per student
- keeps the timer fixed even if the page is refreshed
- helps reduce direct answer copying during practice sessions

## Analytics Features

- Highest score, average score, attempts, and accuracy
- Subject-wise performance charts
- Weak-subject detection
- Attempt-by-attempt score trend
- Global and subject-wise leaderboard
- Quiz history timeline

## Standout Innovation: Smart Coach

Smart Coach is an AI-style recommendation feature that analyzes quiz history and produces:

- Readiness score
- Score momentum
- Weakness insight
- Strength insight
- Recommended next technology and level
- Target score
- 3-step improvement plan

## Adaptive Practice Launcher

From the analytics dashboard, students can click **Start Adaptive Practice**. The system opens the quiz page with the Smart Coach recommended technology and level preselected, creating a practical personalized learning loop.
